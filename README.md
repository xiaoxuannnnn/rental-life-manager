# 合租生活管家

一个面向年轻合租人的轻量网页原型，支持：

- 费用 AA 分摊和垫付差额计算
- 清洁值日排班、完成状态切换和轮换
- 公共物品库存登记与低库存提醒
- 室友公约生效/草案状态管理

## GitHub Pages 部署

本项目的可部署静态页面位于 `docs/index.html`。

发布到 GitHub 后，在仓库设置中进入 `Settings -> Pages`：

- Source 选择 `Deploy from a branch`
- Branch 选择 `main`
- Folder 选择 `/docs`

保存后等待 GitHub Pages 构建完成即可访问。
